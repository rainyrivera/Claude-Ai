# Skills de anuncios (Meta Ads): flujo de 6 pasos

Válidas para cualquier negocio físico, local o digital.

```
1. espia-competencia  →  2. guionista-anuncios  →  3. multiplicador-creatividades
        ↑                                                     ↓
5. vigilante-rentabilidad  ←  (lanzar)  ←  4. plan-testeo-semanal
        ↓  (si el CTR es bueno pero no venden)
6. optimizador-oferta-pagina  →  cambios a testear en 4
```

| # | Skill | Entrada | Salida |
|---|---|---|---|
| 1 | `espia-competencia` | Nicho, país, competidores | Ángulos probados (anuncios con más días activos) |
| 2 | `guionista-anuncios` | Ángulos | Guiones gancho + cuerpo + CTA |
| 3 | `multiplicador-creatividades` | 1 guion | 5 ganchos × 3 formatos = 15 anuncios con nombres medibles |
| 4 | `plan-testeo-semanal` | Anuncios + números del negocio | Calendario de 4 semanas + reglas de pausar/escalar |
| 5 | `vigilante-rentabilidad` | CSV/métricas de Meta | Qué escalar, pausar y qué quema dinero |
| 6 | `optimizador-oferta-pagina` | URL o capturas de la página + métricas | Dónde se pierde la venta, cálculo de oferta y 5 cambios priorizados |

## Cómo usarlas

- **Claude Code**: ya están activas en este repositorio (`.claude/skills/`). Basta con pedirlo ("espía a mi competencia en…") o escribir `/espia-competencia`.
- **claude.ai / app**: sube cada `.zip` de la carpeta `skills-zips/` (en la raíz del repo) desde la sección de Skills de la configuración de claude.ai.

## Requisitos

- Skill 1: acceso a la Biblioteca de Anuncios de Meta (conector de Facebook autorizado o navegador), o capturas y enlaces que aportes tú.
- Skill 6: acceso a la URL de la página (o capturas completas en móvil).
- Skill 5: exportación CSV del Administrador de Anuncios a nivel de anuncio, o métricas pegadas.
